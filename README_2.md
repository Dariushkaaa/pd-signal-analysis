# 🦶 Интерфейс анализа данных сигналов походки (PD Gait Analysis)

Данный модуль веб-системы предназначен для автоматизированной обработки и анализа сигналов инерциальных датчиков (акселерометра и гироскопа) при выполнении **10-метрового ходьбового теста с разворотом**. Система позволяет визуализировать сигналы движения, автоматически выделять фазы ходьбы, корректировать их вручную, рассчитывать биомеханические параметры и оценивать вероятность наличия симптомов болезни Паркинсона.
---

## 🖥 Как устроен интерфейс пользователя

Страница анализа походки состоит из 6 основных визуальных блоков:

---

### 1. 📂 Загрузка данных и запуск анализа
Пользователю предоставляется два удобных способа загрузки данных с мобильного приложения (например, *Sensor Logger*):
* **Загрузить папку (📁):** Автоматически сканирует выбранную директорию и находит файлы `AccelerometerUncalibrated.csv` и `GyroscopeUncalibrated.csv`.
* **Выбрать 2 CSV (📄):** Позволяет вручную выбрать файлы акселерометра и гироскопа.

После проверки структуры данных статус-бар загорается зеленым светом (*«Готово к анализу»*), и становится активна кнопка **«Запустить анализ»**, запускающая вычисления с отображением прогресса в реальном времени.

---

### 2. 🧠 Результат диагностической модели (`resultCard`)
После обработки сервер возвращает итоговое заключение:
* **Уровень уверенности модели:** Оценка в процентах уверенности модели в принятом решении (например, *85%* — с вероятностью 85% модель считает, что сигнал принадлежит определенному классу).
* **:** Отображается в виде цветной плашки (`confidenceBadge`).
* **Диагностический вердикт:** Понятный текстовый результат отображается в виде цветной плашки (`confidenceBadge`) с подписью Healthy(норма), Parkinson's Disease. 

---

### 3. 📈 Интерактивный график сигналов и режим редактирования
Блок содержит интерактивный график трехкомпонентного сигнала акселерометра. На график автоматически наносятся 5 ключевых временных маркеров:
* **T1** — Начало движения;
* **T2** — Конец первого прохода, начало разворота;
* **T3** — Завершение разворота, начало второго прохода;
* **T4** — Конец второго прохода, начало итогового разворота/остановки;
* **T5** — Полное завершение пробы.

#### ✏️ Возможность ручной коррекции (Экспертный режим)
Если нейросеть неточно определила границы разворота из-за случайных помех или артефактов движения:
1. Пользователь нажимает кнопку **«Редактировать точки»**.
2. Кликом на графике или перемещением маркера задает новые временные позиции для точек T1–T5.
3. Нажимает кнопку **«Сохранить и пересчитать»**.

Сервер пересчитывает биомеханические признаки и обновляет диагностический вердикт.

---

### 4. 📊 Рассчитанные показатели и сравнение с нормой

Для глубинного анализа биомеханики система рассчитывает **37 ключевых параметров** и разбивает их на две категории:

1. **Ключевые признаки с границами нормы (`modelFeaturesCard`):**
   * Карточки показателей, влияющих на вердикт модели.
   * Текущее значение сравнивается с нормативным диапазоном здорового контроля (**зеленая зона референса**).
   * Примеры: *Каденс (темп)*, *Энтропия сигнала (сложность движения)*, *Вариабельность времени шага*, *Плавность движения (X_jerk_std)*.

2. **Полный спектр параметров (`allFeaturesCard`):**
   * Все извлеченные характеристики с понятными русскоязычными названиями и единицами измерения:
     * **Временные и пространственные:** *Среднее время шага (с)*, *Количество шагов (шт.)*, *Длительность сегментов (с)*.
     * **Частотные:** *Доминантная частота по осям X, Y, Z (Гц)*.
     * **Динамические и энергетические:** *Амплитуда ускорений*, *Энергия сигнала (RMS)*, *Показатели рывка (Jerk)*.
     * **Симметрия и ритмичность:** *Индекс асимметрии времени шага (%)*, *Индекс застывания (Freeze Index)*.
